01 / TOOLS

One toolkit,
full attack surface.

Six Python scripts that cover the basics of ESP32 hardware security research: read the flash, sniff the bus, parse the layout, verify the boot chain, and let an LLM review what you found.

01

flash_dump.py

Read the full SPI flash over UART using esptool. Custom baud, size, and output path.

sudo python3 flash_dump.py --port /dev/ttyUSB0
02

uart_sniffer.py

Capture raw boot-ROM and runtime UART output. Boot ROM uses 74880 baud, runtime 115200.

python3 uart_sniffer.py --baud 74880
03

firmware_inspect.py

Quick-look at a flash image: ESP32 magic byte, NVS partition, printable strings.

python3 firmware_inspect.py flash.bin --strings
04

partition_table.py

Parse the partition table from a dump and label each entry by type (app/data) and subtype.

python3 partition_table.py flash.bin
05

secure_boot_check.py

Heuristic check for secure boot and flash crypto from a flash dump. Pairs with espefuse.py.

python3 secure_boot_check.py flash.bin
AI
06

llm_firmware_review.py

Send extracted strings to OpenAI or Anthropic for a security review. Local heuristics flag obvious secrets first; the LLM catches the rest.

python3 llm_firmware_review.py flash.bin --provider openai

03 / AI-ASSISTED

An LLM in the
review loop.

Modern firmware is large, stringy, and full of false-positive noise. llm_firmware_review.py runs fast local pattern matching first, then sends a curated sample to an LLM for context-aware triage.

Local-first

  • AWS keys AKIA prefix match
  • Google keys AIza prefix match
  • GitHub PATs ghp_ prefix match
  • Slack tokens xox[abop]- match
  • Private keys PEM block header
  • URLs w/ creds scheme://user:pass@host
  • Hardcoded IPs IPv4 literal in strings
  • Plaintext telnet:// / ftp:// URLs

LLM tier

  • OpenAI gpt-4o-mini default
  • Anthropic claude-3-5-sonnet default
  • Cost 600 strings per call (truncated)
  • Prompt security-review tuned
  • Output bullets + cited strings
  • Privacy nothing sent unless you opt in
OpenAI Anthropic GPT-4o-mini Claude 3.5 100% local fallback
04 / HARDWARE

You probably
already have it.

No custom dev board required. Any ESP32 dev kit and a $3 USB-to-UART bridge is enough to get started.

Required

  • Target ESP32 or ESP8266 dev board
  • Bridge USB-to-UART: CP2102, FTDI, CH340
  • Host Linux, macOS, or WSL
  • Python 3.10 or newer

Recommended

  • Logic Saleae or cheap USB logic analyzer
  • Soldering For non-dev-kit targets
  • Multimeter For verifying voltage levels
  • JTAG ESP-PROG for deeper debugging
ESP32 ESP32-S2 ESP32-S3 ESP32-C3 ESP8266 CP2102 FTDI FT232 CH340
