esp32sec

ESP32 security toolkit. Firmware analysis, UART sniffing, partition parsing, and security posture checks for ESP32/ESP8266 hardware.

# install git clone https://github.com/zhameersheraz/esp32sec.git cd esp32sec && pip install -r requirements.txt
Python 3.10+ MIT license esptool UART hardware

Tools

flash_dump.py

Dump the full ESP32 flash over UART using esptool. Supports custom baud, size, and output path.

uart_sniffer.py

Capture raw boot and runtime UART output (boot ROM uses 74880 baud, runtime is usually 115200).

firmware_inspect.py

Quick-look at a dumped image: ESP32 magic, NVS markers, partition table, printable strings.

partition_table.py

Parse the OTA / NVS / phy / spiffs partition table from a dump and label each entry by type and subtype.

secure_boot_check.py

Heuristic check for secure boot and flash crypto state from a flash dump. Pairs with espefuse.py for ground truth.

Quick start

# 1. dump the flash sudo python3 tools/flash_dump.py --port /dev/ttyUSB0 --output flash.bin # 2. inspect it python3 tools/firmware_inspect.py flash.bin --strings # 3. read the partition table python3 tools/partition_table.py flash.bin # 4. sniff live UART during boot sudo python3 tools/uart_sniffer.py --port /dev/ttyUSB0 --baud 74880
